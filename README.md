# Laboratory_Supply_Tracker
A python system used to manage Lab supplies across different locations it helps the user track quantities and manage inventory  
Features
- Add new laboratory supply items.
- Search for items by ID or location.
- Receive and issue stock.
- Transfer stock between locations.
- Generate low-stock reports.
- Calculate required restocking quantities and costs.
- Save and load inventory data using JSON files.
- Validate inputs and prevent invalid stock operations.
  
Technologies Used
- Python
- Object-Oriented Programming
- Dictionaries and Lists
- JSON for data storage

Project Files
-main.py: Contains the main menu and user interaction.
-SupplyItem.py: Defines the SupplyItem class and its methods.
-SupplyStore.py: Manages inventory operations and data storage.

How to Run
-Make sure Python 3.10 or later is installed.
-Download or clone the repository.
-Open the project folder.
-Run main.py.
-Follow the menu instruction
